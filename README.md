# Royal Door 🌍👑

منصة اجتماعية ملكية عالمية تجمع بين الغرف الصوتية، الألعاب، والهدايا الرقمية.

## 📂 هيكل المشروع
- index.html: الصفحة الرئيسية
- about.html: صفحة التعريف
- update-center.html: مركز التحديث الملكي
- support.html: الدعم الفني
- privacy.html: سياسة الخصوصية
- terms.html: شروط الاستخدام
- assets/css/style.css: تنسيق الألوان والخطوط
- assets/css/animations.css: تأثيرات الحركة
- assets/js/main.js: الأكواد التفاعلية
- assets/images/logo.png: شعار المنصة

## 🚀 كيفية التشغيل
1. افتح `index.html` في المتصفح.
2. أو ارفع المشروع على GitHub واستخدم GitHub Pages لعرضه عالمي
