# Royal Door 🌍👑
**المنصة الملكية المتكاملة لعام 2026**

منصة اجتماعية عالمية تجمع بين الغرف الصوتية، الألعاب، والاستثمار الرقمي الآمن.

## 🚀 محتويات المستودع
- `index.html`: الصفحة الرئيسية (الواجهة الملكية).
- `recharge.html`: مركز شحن الجواهر والكوينز.
- `invest.html`: نظام الاستثمار الملكي.
- `privacy.html`: سياسة الخصوصية المعتمدة لمتجر جوجل.
- `terms.html`: شروط الاستخدام والقوانين.
- `delete.html`: صفحة طلب حذف البيانات (متطلب تقني لجوجل).
- `support.html`: قنوات التواصل الرسمية والدعم الفني.

## 📱 ميزات التطبيق
* غرف صوتية بجودة عالية.
* متجر ملكي متكامل.
* نظام استثمار بربح شهري.
* خصوصية وأمان بمعايير عالمية.
